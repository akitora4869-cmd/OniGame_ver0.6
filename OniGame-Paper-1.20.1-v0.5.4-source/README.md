# 鬼げぇむ v0.5.4

Minecraft Paper 1.20.1 / Java 17 用の非対称鬼ごっこプラグインです。

## 実装済み

- 参加受付、ランダム陣営分け、開始・終了・制限時間
- 鬼2種：堕狐（狐渡り・分霊）、鬼神（鬼突・地砕）
- ぷれいやースキル4種：疾走・隠形・煙幕・破鬼撃
- 複数の心臓、耐久値、破壊時の鬼HP・CT・能力弱体化
- GM操作本による心臓のランダム配置／手動マーカー配置の選択
- 名前付きアーマースタンド型の透明・固定・無敵な心臓地点マーカー
- 堕狐専用装備の自動装着・移動防止と専用リソースパック
- 参加者0人時、GM自身を鬼に割り当てるソロテストモード
- ソロテスト時、未設定のロビー・両陣営開始地点・出口・心臓3個を現在地周辺へ一時自動配置
- GMがぷれいやーとなり、追跡・攻撃・簡易固有能力を使う鬼Botと対戦できるテストモード
- 鬼Bot本体を透明化し、装備だけが見えるホラー向け外見
- 複数人で参加できる正式な「ぷれいやー対鬼Bot」モード
- GMが鬼となり、革装備一式のぷれいやーBot 1～8体と戦うモード
- ぷれいやーBotの心臓探索・損壊・スキルチェック・逃走・脱出AI
- 心臓が残っている間の鬼の自動再生とダメージ軽減
- 満腹度をスタミナとして使用する鬼・ぷれいやー共通の走行制限
- 鬼の通常歩行速度をぷれいやーより20％高速化（設定変更可能）
- 鬼の距離に応じた接近心音、視界判定による発見演出と追跡状態
- 心臓を右クリック作業型の進行目標へ変更し、不定期のSHIFTスキルチェックを追加
- 全心臓破壊後に専用BGM「名もなき剣」を全参加者へ再生
- ソロテスト開始時にテストプレイ本を自動配布し、視線先心臓の即時破壊に対応
- 鬼選択とぷれいやースキル選択をチェストUI化
- 堕狐装備4部位と鬼選択UIへ専用16×16アイコンを追加
- 全滅、鬼討伐、脱出、時間切れの勝敗判定
- アクションバーによる残り時間・心臓数表示
- 画面右サイドバー（ロビー：オンライン数、試合中：残り時間・心臓数・全ぷれいやー状態）

状態アイコンは緑の `● 通常`、黄色の `▲ 瀕死（最大HPの30％以下）`、赤の `✖ 脱落`、白の `◆ 脱出` です。

## 導入

1. Java 17で `mvn clean package` を実行します。
2. `target/OniGame-0.5.4.jar` をPaper 1.20.1サーバーの `plugins` に入れます。
3. サーバーを起動します。

## 初期設定（OP）

立っている場所を各地点として登録します。

```
/og set lobby
/og set player
/og set oni
/og set exit
```

心臓にしたいブロック位置に立って `/og heart` を実行します。複数登録できます。同じ位置でもう一度実行すると削除します。

## GM操作本と心臓配置

`/og gmbook` でクリック操作できるGM本を受け取れます。本からランダム配置・手動配置の切り替え、心臓マーカー取得、マーカー数確認、鬼種別のゲーム開始、停止を操作できます。

- ランダム配置：`/og heart` で登録した候補から `config.yml` の `random-heart-count` 個を抽選します。
- 手動配置：GM本から受け取ったアーマースタンドを置くと「鬼の心臓地点」という名前になり、即座に透明・固定・無敵になります。ゲーム開始時、その全地点に心臓が生成されます。

## 堕狐リソースパック

`OniGame-ResourcePack-v3.zip` を各プレイヤーへ適用してください。堕狐になるとチェーン装備一式が自動装着され、専用の外見になります。装備は試合中に外したり捨てたりできず、試合終了時に自動解除されます。この方式では通常のチェーン装備も堕狐と同じ着用外見になるため、本ゲーム内ではチェーン装備を堕狐専用として扱ってください。インベントリ内ではCustomModelDataにより頭・胴・脚・靴がそれぞれ専用アイコンになり、鬼選択UIの堕狐にも頭装備の `dakoface` が表示されます。

## 参加者0人でのテスト

誰も `/og join` していない状態で、ゲーム内のGMが `/og start dakko` または `/og start kishin` を実行するとソロテストモードになります。ロビー、ぷれいやー開始地点、鬼開始地点、出口、心臓地点は未設定でも開始できます。未設定地点はGMの現在地を基準に一時補完され、心臓地点が1つもなければ前方へ3個を仮生成します。保存済み設定は変更されず、仮生成した心臓はテスト終了時またはプラグイン停止時に撤去されます。

ソロテスト開始時にはホットバー9番へ「テストプレイ本」が自動配布されます。本から視線先の心臓を即時破壊、BGM再生・停止、状態確認、テスト終了ができます。心臓の即時破壊はソロテストを開始したGM本人だけが利用でき、通常試合では使用できません。本を失った場合は `/og testbook` で再取得できます。

### ぷれいやー対鬼Bot戦

`/og join`で参加した後、GMが `/og botgame dakko` または `/og botgame kishin` を実行すると、参加者全員がぷれいやー陣営となり、鬼Botと通常ルールで対戦できます。参加者0人ならGM単独のテストとして開始します。GM本の「ぷれいやーBotテスト」ページからも開始できます。Bot本体と名前表示は透明になり、武器・防具だけが見えます。Botは最寄りの生存ぷれいやーを索敵・追跡・攻撃し、堕狐は簡易テレポート、鬼神は簡易突進を使用します。スタミナ切れ時には追跡を一時休止します。外部プラグインは不要です。

### 鬼対ぷれいやーBot戦

参加者0人で `/og onibotgame dakko 3` または `/og onibotgame kishin 3` を実行すると、GMが鬼となり、指定数のぷれいやーBotと対戦できます。Bot数は1～8です。ぷれいやーBotは本体が透明で、茶色の革装備一式と鉄のツルハシだけが見えます。

ぷれいやーBotは心臓を自動探索して、人間のぷれいやーと同じ速度で継続的に損壊します。4～9秒ごとにスキルチェックが発生し、標準78％の確率で成功します。成功時は進行ボーナス、失敗時は損壊進行の後退・爆発音・鬼への方角通知が発生します。鬼が10ブロック以内へ接近すると心臓作業を中断して逃走し、すべての心臓を破壊すると出口へ向かいます。死亡・脱出は通常の勝敗判定に含まれます。

## 鬼の心臓加護

心臓が1個以上残っている間、鬼と鬼Botは受けるダメージが標準で25％になり、毎秒体力1.0を自動回復します。最後の心臓が破壊されると、ダメージ軽減と自動再生は完全に解除されます。`config.yml` の `oni-heart-protection` で調整できます。

## スタミナ

満腹度ゲージを最大20のスタミナとして使用します。走りながら移動すると毎秒2.0消費し、止まる・歩くと毎秒1.5、しゃがむと毎秒2.5回復します。0になると走行が解除されます。鬼とぷれいやーの両方に適用され、数値は `config.yml` の `stamina` で変更できます。

## 選択UI

`/og join`すると、ぷれいやースキル選択用のチェストUIが自動で開きます。`/og skills`でも再表示でき、疾走・隠形・煙幕・破鬼撃をアイテムから選択できます。GMはGM本の「鬼を選択」または `/og onimenu` から堕狐・鬼神を選び、「選択した鬼で開始」でゲームを開始できます。従来の `/og skill` と `/og start dakko|kishin` も引き続き利用できます。

## 移動速度

標準設定はぷれいやー `0.20`、鬼 `0.24` です。直線では鬼が徐々に追いつくため、ぷれいやーはスキル・妨害アイテム・地形を使って距離を作る必要があります。速度は `config.yml` の `player-walk-speed` と `oni-walk-speed` で調整できます。

## ホラー・追跡システム

鬼が28ブロック以内に近づくと接近距離に応じた心音が鳴ります。鬼の24ブロック以内・視野110度・遮蔽物なしの条件で発見されると、警告タイトル・暗転・警告音とともに追跡状態へ入ります。鬼の視界を8秒間切ると追跡を解除できます。数値は `oni-terror-radius`、`oni-detection-range`、`oni-field-of-view`、`chase-lost-seconds` で変更できます。

## 心臓の進行作業

心臓は通常の採掘では破壊できません。心臓を右クリックすると作業を開始し、その場にいる間は自動で進行します。もう一度右クリックする、3.5ブロック以上離れる、攻撃を受けると中断します。初期設定は耐久100・0.5秒ごとに1進行なので、1人なら約50秒、複数人なら協力人数に応じて短縮されます。

作業中は4～9秒ごとに不定期のスキルチェックが発生します。画面下の白いカーソルが緑の成功範囲へ入った瞬間にSHIFTを押してください。成功すると3進行のボーナス、早すぎる・遅すぎる・無入力の場合は8進行後退し、大きな音と方角が鬼へ通知されます。通常の作業音による方角通知は5秒間隔です。

## 最終局面BGM

すべての心臓が破壊されると、全参加者へリソースパック内の `onigame:final_phase` が再生されます。収録音源は「名もなき剣」（メタデータ上のアーティスト: ulala）で、長さは約193秒です。ゲーム終了時には自動停止します。`/og bgmtest` で試聴、`/og bgmstop` で停止できます。別のサウンドIDへ変える場合は `/og bgm <ID>` を使用します。

## 遊び方

```
/og join
/og skill sprint
/og start dakko
```

スキルは `sprint`, `invisible`, `smoke`, `strike`。鬼は `dakko` または `kishin` です。鬼種を省略するとランダムになります。右クリックで配布されたスキルを使用します。

心臓は右クリックで作業を開始し、SHIFTスキルチェックを成功させながら進行させます。全心臓破壊後に脱出口へ入るか、弱体化した鬼を倒せばぷれいやーの勝利です。
